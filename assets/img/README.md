# 이미지 넣는 곳

이 폴더에 아래 이름 그대로 파일을 넣으면 홈페이지에 자동으로 적용됩니다.
파일이 없으면 코드로 그린 기본 도형이 대신 표시되므로, 없어도 홈페이지는 깨지지 않습니다.

| 파일 이름 | 쓰이는 곳 | 없을 때 |
|---|---|---|
| `logo-mark.png` | 헤더·푸터에서 상호 글자 앞 | 글자 로고만 표시 |
| `doctor.jpg` | 의료진 소개 사진 | 의사 일러스트 표시 |
| `quokka-happy.png` | 히어로, 검사 진행 화면 | 코드로 그린 쿼카 |
| `quokka-smile.png` | 예약 배너, 정상 결과 | 코드로 그린 쿼카 |
| `quokka-worry.png` | '이런 마음이라면' 섹션, 심한 결과 | 코드로 그린 쿼카 |
| `quokka-wink.png` | 성격·성향 검사 결과 | 코드로 그린 쿼카 |

## 권장 사양

- **`logo-mark.png`** — 정사각형, **배경 투명 PNG**, 512×512px 이상.
  SVG를 쓰려면 파일명을 `logo-mark.svg` 로 두고 `index.html` 의 `src` 두 곳도 함께 바꾸세요.
- **`doctor.jpg`** — 정사각형에 가깝게, 800×800px 이상. 얼굴이 위쪽에 오도록 잘라주세요.
- **`quokka-*.png`** — **정사각형, 배경 투명 PNG**, 400×400px 이상 권장.
  캐릭터가 정사각형 안에 꽉 차지 않게, 여백을 조금 두고 가운데에 놓아주세요.
  네 표정이 같은 캐릭터로 보이도록 **크기와 위치를 맞춰서** 만드시는 것이 중요합니다.

### 배경이 흰색인 이미지라면

저장소의 [`tools/배경지우기.html`](../../tools/배경지우기.html) 을 브라우저로 열어
이미지를 끌어다 놓으면 흰 배경이 투명해집니다. 설치할 것이 없고,
이미지는 브라우저 안에서만 처리되어 어디로도 전송되지 않습니다.
쓰임새를 고르고 저장하면 아래 표의 파일 이름으로 바로 내려받아집니다.

밝은 배경·어두운 배경 미리보기가 나란히 나오니, 초록 배너 위에서도
어색하지 않은지 확인한 뒤 저장하세요.

### 쿼카 이미지를 하나만 가지고 계신다면

같은 파일을 이름만 바꿔 네 개로 복사해 넣으면 됩니다. 표정 변화는 없어지지만
사이트 전체에서 그 그림이 쓰입니다.

```
cp 내그림.png assets/img/quokka-happy.png
cp 내그림.png assets/img/quokka-smile.png
cp 내그림.png assets/img/quokka-worry.png
cp 내그림.png assets/img/quokka-wink.png
```

일부만 넣어도 됩니다. 넣은 표정은 이미지로, 나머지는 코드로 그린 쿼카로 표시됩니다
(다만 그림체가 섞여 보이므로 네 개를 모두 채우시는 편이 낫습니다).

## 주의

- `logo-mark.png` 는 **마크(그림)만** 있는 이미지를 넣어주세요.
  상호("수원숲 정신건강의학과")는 홈페이지가 글자로 직접 그리므로,
  글자까지 들어간 로고를 넣으면 글자가 두 번 나옵니다.
- 배경이 흰색으로 채워진 이미지를 넣으면 다크 모드에서 흰 사각형이 보입니다.
  반드시 배경이 투명한 PNG를 쓰세요.

## 파일을 넣은 뒤

```
node build-single.js
```

를 실행하면 이미지가 `dist/index.html` 안에 자동으로 포함됩니다.
(파일 하나만 올려도 로고와 사진이 함께 표시됩니다.)
