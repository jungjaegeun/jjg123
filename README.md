# 수원숲 정신건강의학과의원 홈페이지

정적 파일만으로 동작하는 병원 홈페이지입니다. 빌드 도구나 서버 없이 `index.html`을 열면 바로 실행됩니다.

## 구조

```
index.html              홈페이지 (원페이지)
assets/css/styles.css   디자인 토큰 · 라이트/다크 테마 · 반응형
assets/js/screenings.js 자가진단 척도 데이터 + 채점 로직
assets/js/main.js       테마·네비게이션·자가진단 진행 UI
assets/img/             로고·의료진 사진을 넣는 곳 (선택)
build-single.js         파일 하나(dist/index.html)로 합치는 빌드 스크립트
```

## 섹션

히어로 → 이런 마음이라면 → 진료 안내 → 무료 자가진단 → 의료진 소개 →
진료시간·오시는 길 → 자주 묻는 질문 → 예약 CTA → 푸터

## 자가진단 (13종)

공개된 선별 척도 13종이 문항 제시부터 채점·해석까지 실제로 동작합니다.
카드 위 분류 칩(전체 / 우울·기분 / 불안·스트레스 / 수면·집중 / 웰빙·생활)으로 걸러 볼 수 있습니다.

| 분류 | 검사 | 척도 | 문항 | 채점 |
|---|---|---|---|---|
| 우울·기분 | 우울 | PHQ-9 | 9 | 총점 0–27 |
| 우울·기분 | 일상 우울감 | CES-D | 20 | 총점 0–60 (4·8·12·16번 역채점) |
| 우울·기분 | 조울(양극성) | MDQ | 15 | 증상 7개 이상 **+** 같은 시기 **+** 중간 이상 손상 |
| 우울·기분 | 산후 우울 | EPDS | 10 | 총점 0–30 (문항마다 보기 순서가 다름) |
| 불안·스트레스 | 불안 | GAD-7 | 7 | 총점 0–21 |
| 불안·스트레스 | 스트레스 | PSS-10 | 10 | 총점 0–40 (4·5·7·8번 역채점) |
| 불안·스트레스 | 우울·불안·스트레스 | DASS-21 | 21 | 하위 척도 3개 각각 0–42 (×2), 척도마다 다른 기준 |
| 불안·스트레스 | 외상후 스트레스 | PCL-5 | 20 | 총점 0–80 (31점 이상 시사) |
| 불안·스트레스 | 강박 | OCI-R | 18 | 총점 0–72 (21점 이상 시사) |
| 수면·집중 | 불면증 | ISI | 7 | 총점 0–28 |
| 수면·집중 | 성인 ADHD | ASRS-v1.1 Part A | 6 | 문항별 기준 초과 개수 (4개 이상 시사) |
| 웰빙·생활 | 마음 웰빙 | WHO-5 | 5 | 원점수 ×4 = 0–100 (**점수가 높을수록 좋음**) |
| 웰빙·생활 | 음주 습관 | AUDIT | 10 | 총점 0–40 |

- 응답과 결과는 `localStorage`(`suwonsup.screening.v1`)에만 저장되며 서버로 전송되지 않습니다.
- 결과 화면의 '기록 삭제' 버튼으로 언제든 지울 수 있습니다.
- PHQ-9 9번, EPDS 10번(자해 관련)에 응답하면 위기상담 안내가 함께 표시됩니다.
- 선별(screening) 참고용이며 의학적 진단이 아니라는 안내를 카드·결과·푸터에 모두 표기했습니다.

### 검사를 추가·수정할 때

`assets/js/screenings.js` 의 `SCREENINGS` 배열에 항목을 넣으면 카드와 진행 화면이 자동 생성됩니다.
채점 방식은 `scoring.type` 으로 고릅니다.

| type | 쓰임 | 예 |
|---|---|---|
| `sum` | 총점 합산. `reverse` 로 역채점, `multiplier`/`displayMax` 로 환산 | PHQ-9, WHO-5 |
| `threshold` | 문항별 기준값을 넘은 개수 | ASRS |
| `subscales` | 하위 척도별 점수·등급. 해설은 `toneText` 에서 가져옴 | DASS-21 |
| `mdq` | 증상 수 + 동시성 + 기능 손상의 3중 조건 | MDQ |

문항마다 보기가 다르면 문자열 대신 `{ text, options }` 객체를 넣으면 됩니다.

### 문항 표현에 대한 참고

각 척도의 원 출처는 공개되어 있으나, 이 파일의 한국어 문항은 널리 통용되는 표현을 옮긴 것으로
특정 기관의 공식 번역본과 글자 그대로 일치하지는 않을 수 있습니다.
실제 진료에 활용하실 때는 원장님이 문항 표현을 한 번 검토해 주시길 권합니다.

## 이미지 (선택)

`assets/img/` 에 파일을 넣으면 자동으로 적용되고, 없으면 코드로 그린 도형이
대신 표시됩니다. 자세한 규격은 [`assets/img/README.md`](assets/img/README.md) 참고.

| 파일 | 쓰이는 곳 | 없을 때 |
|---|---|---|
| `assets/img/logo-mark.png` | 상호 글자 앞 그림 마크 (배경 투명) | 글자 로고만 표시 |
| `assets/img/doctor.jpg` | 의료진 소개 사진 | 의사 일러스트 표시 |

`build-single.js` 가 이 이미지들을 data URI 로 `dist/index.html` 안에 심어 넣으므로,
파일 하나만 올려도 로고와 사진이 함께 표시됩니다.

## 아직 확인·교체가 필요한 부분

- **원장 소개 문구** — `#doctor` 의 `.doctor-quote` 는 예시로 작성한 문장입니다.
  원장님 본인의 말로 바꾸거나 삭제하세요.
- 사업자등록번호·대표자 등 푸터 표기 항목 (현재는 표시하지 않음)
- 약도(`.minimap`)는 직접 그린 간이 약도입니다. 실제 지도를 쓰려면
  네이버/카카오 지도 iframe으로 교체하세요.

## 파일 하나로 배포하기

```
node build-single.js
```

`dist/` 폴더가 만들어집니다. CSS·JS가 모두 `dist/index.html` 안에 들어 있어
이 폴더를 웹호스팅(Netlify Drop 등)에 그대로 올리면 됩니다.

## 커스터마이즈

- **검사 추가/수정**: `assets/js/screenings.js`의 `SCREENINGS` 배열에 항목을 추가하면 카드와 진행 화면이 자동 생성됩니다.
  문항별로 보기가 다르면 문자열 대신 `{ text, options }` 객체를 넣으면 됩니다.
