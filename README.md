# 수원숲정신건강의학과 홈페이지

정적 파일만으로 동작하는 병원 홈페이지입니다. 빌드 도구나 서버 없이 `index.html`을 열면 바로 실행됩니다.

## 구조

```
index.html              홈페이지 (원페이지)
assets/css/styles.css   디자인 토큰 · 라이트/다크 테마 · 반응형
assets/js/screenings.js 자가진단 척도 데이터 + 채점 로직
assets/js/main.js       테마·네비게이션·자가진단 진행 UI
app/                    기존 '불안 관리 앱' (공황 버튼 · 명상 · 산책 · 감정 일기)
```

## 섹션

히어로 → 이런 마음이라면 → 진료 안내 → 무료 자가진단 → 의료진 소개 →
진료시간·오시는 길 → 셀프케어 앱 → 자주 묻는 질문 → 예약 CTA → 푸터

## 자가진단

임상에서 널리 쓰이는 공개 선별 척도 5종이 실제로 동작합니다.

| 검사 | 척도 | 문항 | 채점 |
|---|---|---|---|
| 우울 | PHQ-9 | 9 | 총점 0–27 |
| 불안 | GAD-7 | 7 | 총점 0–21 |
| 불면증 | ISI | 7 | 총점 0–28 |
| 성인 ADHD | ASRS-v1.1 Part A | 6 | 문항별 기준 초과 개수 (4개 이상 시 시사) |
| 스트레스 | PSS-10 | 10 | 총점 0–40 (4·5·7·8번 역채점) |

- 응답과 결과는 `localStorage`(`suwonsup.screening.v1`)에만 저장되며 서버로 전송되지 않습니다.
- 결과 화면의 '기록 삭제' 버튼으로 언제든 지울 수 있습니다.
- PHQ-9 9번(자해·죽음에 대한 생각)에 응답하면 위기상담 안내가 함께 표시됩니다.
- 선별(screening) 참고용이며 의학적 진단이 아니라는 안내를 카드·결과·푸터에 모두 표기했습니다.

## 실제 정보로 교체해야 하는 부분

`○○` 로 표시되거나 아래에 해당하는 값은 자리표시자입니다.

- 대표번호 `031-000-0000` — `index.html` 안의 모든 `tel:` 링크와 `assets/js/main.js`의 결과 화면 예약 버튼
- 주소, 지하철역, 주차 안내 (`#visit` 섹션)
- 원장 성함·약력 (`#doctor` 섹션)
- 사업자등록번호, 대표자, 팩스 (푸터)
- 진료시간 (`.hours` 표)
- 지도: `.map-placeholder` 자리에 네이버/카카오 지도 iframe 삽입

## 커스터마이즈

- **색상**: `assets/css/styles.css` 상단 `:root` / `[data-theme="dark"]` 변수만 바꾸면 전체 톤이 바뀝니다.
- **검사 추가/수정**: `assets/js/screenings.js`의 `SCREENINGS` 배열에 항목을 추가하면 카드와 진행 화면이 자동 생성됩니다.
  문항별로 보기가 다르면 문자열 대신 `{ text, options }` 객체를 넣으면 됩니다.
