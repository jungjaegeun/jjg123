# 이미지 넣는 곳

이 폴더에 아래 이름 그대로 파일을 넣으면 홈페이지에 자동으로 적용됩니다.
파일이 없으면 코드로 그린 기본 도형이 대신 표시되므로, 없어도 홈페이지는 깨지지 않습니다.

| 파일 이름 | 쓰이는 곳 | 권장 사양 |
|---|---|---|
| `logo-mark.png` | 헤더·푸터 로고 | 정사각형, **배경 투명 PNG**, 512×512px 이상 (SVG면 더 좋음 — 이름을 `logo-mark.svg` 로 바꾸고 `index.html`의 `src` 도 함께 수정) |
| `doctor.jpg` | 의료진 소개 사진 | 정사각형에 가깝게, 800×800px 이상. 얼굴이 위쪽에 오도록 잘라주세요 |

## 주의

- `logo-mark.png` 는 **마크(원 + 나무)만** 있는 이미지를 넣어주세요.
  글자("수원숲 정신건강의학과")는 홈페이지가 직접 글자로 그리기 때문에,
  글자까지 들어간 로고를 넣으면 글자가 두 번 나옵니다.
- 배경이 흰색으로 채워진 이미지를 넣으면 다크 모드에서 흰 사각형이 보입니다.
  반드시 배경이 투명한 PNG를 쓰세요.

## 파일을 넣은 뒤

```
node build-single.js
```

를 실행하면 이미지가 `dist/index.html` 안에 자동으로 포함됩니다.
(파일 하나만 올려도 로고와 사진이 함께 표시됩니다.)
