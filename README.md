# 수원숲 정신건강의학과의원 홈페이지

정적 파일만으로 동작하는 병원 홈페이지입니다. 빌드 도구나 서버 없이 `index.html`을 열면 바로 실행됩니다.

## 구조

```
index.html              홈페이지 (원페이지)
assets/css/styles.css   디자인 토큰 · 라이트/다크 테마 · 반응형
assets/js/screenings.js 채점 엔진 + 임상 선별 척도 13종
assets/js/profiles.js   성격·성향 검사 5종
assets/js/tasks.js      집중력 과제 3종 (반응 시간 측정, 자체 실행부)
assets/js/main.js       테마·네비게이션·검사 진행 UI
assets/img/             로고·의료진 사진을 넣는 곳 (선택)
build-single.js         파일 하나(dist/index.html)로 합치는 빌드 스크립트
tools/배경지우기.html    캐릭터 이미지의 흰 배경을 투명하게 바꾸는 도구 (브라우저에서 실행)
```

## 섹션

히어로 → 이런 마음이라면 → 진료 안내 → 무료 자가진단 → 의료진 소개 →
진료시간·오시는 길 → 자주 묻는 질문 → 예약 CTA → 푸터

## 자가진단 — 임상 선별 척도 (13종)

공개된 선별 도구 13종이 문항 제시부터 채점·해석까지 실제로 동작합니다.
카드 위 분류 칩(전체 / 우울·기분 / 불안·스트레스 / 수면·집중 / 웰빙·생활)으로 걸러 볼 수 있습니다.

> **홈페이지에는 원 척도명(PHQ-9 등)을 표시하지 않습니다.**
> 화면에는 `label` 에 정의된 중립적인 한글 이름(‘우울 선별’ 등)만 나옵니다.
> 아래 대조표는 **이 저장소 안에서만** 관리되는 참고 자료이며,
> `index.html` · `assets/` · `dist/` 어디에도 척도 약어는 포함되지 않습니다.

| 분류 | 화면 표시 이름 | 근거 척도 | 문항 | 채점 |
|---|---|---|---|---|
| 우울·기분 | 우울 자가진단 / 우울 선별 | PHQ-9 | 9 | 총점 0–27 |
| 우울·기분 | 일상 우울감 검사 / 우울감 척도 | CES-D | 20 | 총점 0–60 (4·8·12·16번 역채점) |
| 우울·기분 | 조울(양극성) 자가진단 / 기분 변동 선별 | MDQ | 15 | 증상 7개 이상 **+** 같은 시기 **+** 중간 이상 손상 |
| 우울·기분 | 산후 우울 자가진단 / 산후 우울 선별 | EPDS | 10 | 총점 0–30 (문항마다 보기 순서가 다름) |

| 웰빙·생활 | 마음 웰빙 지수 / 웰빙 지수 | WHO-5 | 5 | 원점수 ×4 = 0–100 (**점수가 높을수록 좋음**) |
| 웰빙·생활 | 음주 습관 자가진단 / 음주 선별 | AUDIT | 10 | 총점 0–40 |

- 응답과 결과는 `localStorage`(`suwonsup.screening.v1`)에만 저장되며 서버로 전송되지 않습니다.
- 결과 화면의 '기록 삭제' 버튼으로 언제든 지울 수 있습니다.
- PHQ-9 9번, EPDS 10번(자해 관련)에 응답하면 위기상담 안내가 함께 표시됩니다.
- 선별(screening) 참고용이며 의학적 진단이 아니라는 안내를 카드·결과·푸터에 모두 표기했습니다.

## 성격 · 성향 검사 (5종)

증상을 재는 임상 척도가 아니라 성격·관계·흥미·의사결정 성향을 보는 검사입니다.
좋고 나쁨을 가리지 않으므로 심각도 등급(tone) 대신 중립 표시를 씁니다.

| 화면 표시 이름 | 문항 | 채점 | 결과 형태 |
|---|---|---|---|
| 성격 5요인 검사 | 20 | 5차원 × 4문항, 역채점 10문항 | 차원별 막대 |
| 애착 유형 검사 | 12 | 불안·회피 두 축 → 4유형 | 유형 카드 + 축 막대 |
| 직업 흥미 검사 | 30 | 6유형 × 5문항, 상위 3개 코드 | 유형 카드 + 순위 |
| 에니어그램 성격 검사 | 27 | 9유형 × 3문항, 최고점 유형 | 유형 카드 + 순위 |
| 투자 · 소비 심리 검사 | 16 | 4차원 × 4문항 | 차원별 막대 |

**문항 출처** — 성격 5요인은 퍼블릭 도메인 공개 문항 은행의 축약형을 한국어로 옮겼고,
나머지 4종은 통용되는 개념을 바탕으로 **직접 작성**해 저작권 문제가 없습니다.
에니어그램은 학술적으로 검증된 진단 도구가 아니라는 점을 결과 화면에 명시했습니다.

## 집중력 과제 (3종)

설문이 아니라 반응 시간·정확도를 직접 재는 과제입니다.
`assets/js/tasks.js` 가 데이터와 실행부를 모두 가지고 있고, `TASK_RUNNERS[id](host, done)`
형태로 호출되어 결과 객체를 돌려줍니다.

| 과제 | 측정 | 종료 조건 |
|---|---|---|
| 반응 속도 테스트 | 단순 반응 시간 (5회 평균) | 5회 완료 |
| 스트룹 검사 | 정확도 + 간섭 비용(불일치 − 일치) | 20문항 |
| 숫자 폭 검사 | 정확히 기억한 최대 자릿수 | 2회 연속 실패 또는 12자리 |

- 결과는 **규준(norm)에 근거한 평가가 아니라 그 순간의 기록**입니다.
  기기 성능·화면 반응 속도·주변 소음에 따라 쉽게 달라진다는 안내를 결과 화면에 넣었습니다.
- `runTask` 는 정리 함수를 돌려주며, 오버레이를 닫을 때 타이머와 이벤트를 해제합니다.

### 검사를 추가·수정할 때

`assets/js/screenings.js` 의 `SCREENINGS` 배열에 항목을 넣으면 카드와 진행 화면이 자동 생성됩니다.
채점 방식은 `scoring.type` 으로 고릅니다.

| type | 쓰임 | 예 |
|---|---|---|
| `sum` | 총점 합산. `reverse` 로 역채점, `multiplier`/`displayMax` 로 환산 | PHQ-9, WHO-5 |
| `threshold` | 문항별 기준값을 넘은 개수 | ASRS |
| `subscales` | 하위 척도별 점수·등급. 해설은 `toneText` 에서 가져옴 | DASS-21 |
| `mdq` | 증상 수 + 동시성 + 기능 손상의 3중 조건 | MDQ |
| `profile` | 차원별 점수와 높음/보통/낮음 (심각도 아님) | 성격 5요인, 투자 성향 |
| `types` | 유형별 점수를 매겨 상위 `topN` 선택 | 직업 흥미, 에니어그램 |
| `axes` | 두 축의 높낮이 조합(`matrix`)으로 유형 결정 | 애착 유형 |

문항마다 보기가 다르면 문자열 대신 `{ text, options }` 객체를 넣으면 됩니다.

### 문항 표현과 저작권에 대한 참고

- 각 척도의 원 출처는 공개되어 있으나, 이 파일의 한국어 문항은 널리 통용되는 표현을 옮긴 것으로
  특정 기관의 공식 번역본과 글자 그대로 일치하지는 않을 수 있습니다.
  실제 진료에 활용하실 때는 원장님이 문항 표현을 한 번 검토해 주시길 권합니다.
- 화면에서 척도명을 뺀 것은 노출을 줄이기 위한 조치이며, **저작권 쟁점은 이름이 아니라 문항 문구에 있습니다.**
  이름을 감춘다고 문항 사용에 대한 권리 문제가 해소되지는 않습니다.
- 반대로 일부 척도(EPDS, DASS 등)는 사용 시 출처 표기를 권장하므로,
  표기를 없앤 현재 방식이 각 척도의 이용 조건에 맞는지는 원장님이 확인해 주셔야 합니다.
- 가장 안전한 방법은 이용 조건이 명확히 자유로운 척도만 남기거나,
  문항을 병원에서 직접 작성한 문진 문항으로 바꾸는 것입니다.

## 이미지 (선택)

`assets/img/` 에 파일을 넣으면 자동으로 적용되고, 없으면 코드로 그린 도형이
대신 표시됩니다. 자세한 규격은 [`assets/img/README.md`](assets/img/README.md) 참고.

| 파일 | 쓰이는 곳 | 없을 때 |
|---|---|---|
| `assets/img/logo-mark.png` | 상호 글자 앞 그림 마크 (배경 투명) | 글자 로고만 표시 |
| `assets/img/doctor.jpg` | 의료진 소개 사진 | 의사 일러스트 표시 |
| `assets/img/quokka-happy.png` | 히어로, 검사 진행 화면 | 코드로 그린 쿼카 |
| `assets/img/quokka-smile.png` | 예약 배너, 정상 결과 | 코드로 그린 쿼카 |
| `assets/img/quokka-worry.png` | '이런 마음이라면', 심한 결과 | 코드로 그린 쿼카 |
| `assets/img/quokka-wink.png` | 성향 검사 결과 | 코드로 그린 쿼카 |

`build-single.js` 가 이 이미지들을 data URI 로 `dist/index.html` 안에 심어 넣으므로,
파일 하나만 올려도 로고와 사진, 캐릭터가 함께 표시됩니다.

캐릭터는 HTML 에 직접 쓰인 자리(히어로·배너 등)와 JS 가 만들어내는 자리
(검사 진행·결과 화면) 양쪽에서 쓰입니다. JS 쪽은 경로를 문자열로 조립하므로
빌드 시 정규식으로 치환할 수 없어, `build-single.js` 가 표정별 data URI 를
`window.QUOKKA_SRC` 로 주입하고 `main.js` 가 그 값을 우선 사용합니다.
이 처리가 없으면 히어로만 사용자 이미지로 바뀌고 결과 화면은 기본 그림이 남습니다.

## 아직 확인·교체가 필요한 부분

- **원장 소개 문구** — `#doctor` 의 `.doctor-quote` 는 예시로 작성한 문장입니다.
  원장님 본인의 말로 바꾸거나 삭제하세요.
- 사업자등록번호·대표자 등 푸터 표기 항목 (현재는 표시하지 않음)
- 약도(`.minimap`)는 직접 그린 간이 약도입니다. 실제 지도를 쓰려면
  네이버/카카오 지도 iframe으로 교체하세요.

## 파일 하나로 배포하기
